# 🥢 中国式饭局 · 点菜模拟器

👉 **[点击在线开单（GitHub Pages）](https://shaoxiangm.github.io/diancai-simulator/)**

先看人数、预算和客人忌口，再在复写纸联单上勾菜。交给后厨前，按住菜名右侧的 `≡` 拖动调整上菜顺序。出菜后翻到联单背面，查看大堂经理的红笔批注、机打热敏结账小票与职级印章。

### ✨ 核心玩法与特色

* **主线八关 · 一关一潜规则**：从楼下川菜家常饭、老丈人鲁菜寿宴、西关早茶茶位费、发薪前夜 24 元极限凑份子，一路闯到湘菜变态辣、两千元商务茅台局、东北串摊与驻京办年度终极接待；八关全胜后解锁自由接单模式。
* **百道菜库 · 地域与档次双隔离**：内置近百道中式菜肴与酒水，涵盖闽东、闽南、广府、川渝、湖湘、鲁豫、沪上、东北八大风味，并按**「街边小馆 / 中高档酒楼 / 高端接待席」**严格分层（街边小馆绝不乱入刺身与天价茅台），一店一单动态开席。
* **真实饭局人情世故引擎**：
  * **南北喝汤次序**：粤闽等南方席讲究先汤后菜，鲁豫东北等北方席讲究先菜后汤，上错顺序会被大堂经理当场点名。
  * **地方规矩与一锅出**：粤闽茶楼自动按人数开茶位（敢当众退茶位另有奇效）；东北铁锅炖大鹅自带贴饼与配菜，享“一锅顶全席”豁免。
  * **酒水与解辣博弈**：开车局滴酒不沾、商务局必开酱香好酒、重辣局全靠椰汁与热玉米汁续命。
* **突发快餐支线彩蛋**：主线第 2～7 关过关后，有概率随机夹进**「上校炸鸡铺 · 疯狂星期五」**（50 元精准卡点）与**「银拱门快餐厅 · 1+1 随心配」**（两白两红配对）支线小游戏，绝不卡主线进度。
* **8 级职级印章 & 18 枚成就档案**：从「试用期端茶小弟」一路晋升至「驻京办首席司长」，收录 8 枚常规接待章与 10 枚席间奇葩彩蛋（如「包厢要饭人」「脸皮厚之人」「但凡多吃一颗花生米」「从小喝到大」「不喝椰汁的是卧底」等）。
* **热敏结账小票 & 踢馆战报**：结算背面附带机打结账小票复盘点单明细，支持一键生成联单战报图与好友踢馆口令链接。
* **纯前端单文件架构**：所有 HTML、CSS 与原生 JavaScript 均封装在单个 `index.html` 中，零外部构建依赖，下载后浏览器打开即玩，关卡与成就自动保存在当前浏览器。

### 🗂️ 代码结构速览

单文件 [`index.html`](./index.html) 内部严格划分为四个独立模块，数据与渲染完全解耦：

1. **`MODULE 1: DISHES_DB`**：全库菜品、酒水、茶位费、门店最低档次（`minTier`）及快餐支线菜单数据。
2. **`MODULE 2: SCENARIOS_DB`**：主线八大剧本、随机支线抽取器及基于地域与门店档次的动态水单生成器（`buildStoreMenu`）。
3. **`MODULE 3: JUDGE_ENGINE`**：纯函数五维评分引擎（预算把控、面子排场、食客体感、识菜避坑、上菜节奏）与 18 枚成就判定树。
4. **`MODULE 4: UI_APP`**：复写纸联单渲染、封面 3D 翻开与结算翻面动效、触屏拖拽排菜序、热敏小票及 Canvas 战报图导出。

### 🚀 本地运行

无需安装 Node.js 或任何打包工具，直接克隆仓库并用任意现代浏览器打开 `index.html` 即可游玩：

```bash
git clone https://github.com/shaoxiangm/diancai-simulator.git
cd diancai-simulator
```

## 游戏简介与核心特色

**《点菜模拟器》（Diancai Simulator）** 是一款基于复古复写纸点菜单设计的单文件 HTML5 网页小游戏，无需下载安装，打开浏览器即可体验中国式饭局的预算把控与酒桌博弈。

* **复古物理质感**：还原国营老饭店复写纸双联单、蓝黑钢笔勾菜、红泥印章与拟真翻页、后厨出单及热敏纸打印音效。
* **八大菜系与门店档次隔离**：覆盖主线八大菜系接待关卡与极限凑份子挑战，区分平价小馆与高档酒楼动态水单，防踩预制菜雷区。
* **动态突发事件与信息迷雾**：局内随机触发后厨食材沽清、主宾临时加人、隐蔽忌口试探等突发状况，考验临场应变。
* **Roguelike 无限模式与每日统考**：通关后解锁无限组合的饭局词缀，支持“今日全网统考”每日同题水单比拼。
* **经理毒舌批注与 18 枚成就**：结账自动生成带职级印章的热敏小票战报长图，支持一键分享与 18 枚奇葩成就收集。

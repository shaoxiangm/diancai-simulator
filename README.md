## 游戏简介与核心特色

**《点菜模拟器》（Diancai Simulator）** 是一款基于复古复写纸点菜单设计的单文件 HTML5 网页小游戏，无需下载安装，打开浏览器即可体验中国式饭局的预算把控、座次礼数与酒桌博弈。

- **复古复写纸物理质感**：还原国营老饭店复写纸双联单、蓝黑钢笔勾菜、红泥印章，配备 Web Audio 合成翻页、勾划、后厨摇铃与热敏小票打印音效。
- **八大菜系与馆子分级定价**：收录 99 道涵盖八大菜系的中餐菜品与酒水，区分街边小馆、中高档酒楼与高端接待席，茶位费与菜价随门店档次动态浮动，暗藏预制菜与外地招牌陷阱。
- **包厢圆桌“排座次”系统**：在商务大客户局与驻京办终极接待中解锁圆桌座次图，将底部托盘中的宾客铭牌拖入对应席位，考验“主陪正对门、主宾居右手、经手人守门口”的酒桌规矩。
- **中国式人情世故微博弈**：
  - **结账抢买单三回合心理战**：在老同学聚会与商务局中拉扯“客气值”与“面子值”，既可实现“零元得体免单”，也可能推搡过猛导致“收银台摔跤社死”。
  - **扫码共享点餐保卫战**：应对队友扫码偷偷往购物车塞龙虾、飞天酒的 15 秒手速拦截战。
- **先爽后难八大主线 + 隐藏彩蛋**：涵盖家常川菜、老广早茶（支持当众退茶位）、发薪前夜 24 元极限凑份子（支持薅光三样免费福利）、同学撸串、长辈寿宴、湘菜变态辣、商务请托与驻京办终宴，途中随机插入快餐彩蛋水单。
- **动态突发事件与信息迷雾**：局内随机触发后厨沽清、临时加人、下午开车禁酒、主厨力荐尖货等公关二选一事件，部分关卡还藏有需从细节推理的隐藏忌口。
- **Roguelike 无限模式与每日统考**：通关后解锁“全桌痛风预警”“一山不容二虎”“极致抠门财务”等随机词缀自由接单，支持“今日全网统考”每日同题水单比拼。
- **经理毒舌批注与 33 枚成就**：结账自动生成带职级印章的热敏小票战报长图，支持一键复制战报踢馆链接与 **33 枚**常规及隐藏彩蛋成就收集。

## 玩法速览

1. **审单看忌口**：接过派单简报，摸清到席人数、报销红线、隐蔽忌口以及南汤北汤上菜习惯。
2. **联单勾菜**：按分类挑选菜品与酒水，留意菜品描述与钢笔浮签提示，防止点出料理包或超支。
3. **排菜序 & 排座次**：在后厨排单页拖动 `≡` 安排“凉菜 → 热菜 → 汤品”上菜节奏；商务与终极接待局需切换到「包厢座次」拖入宾客铭牌。
4. **临场公关 & 结账**：应对突发事件抉择与结账推拉博弈，翻面查看五维考评、经理红笔批注与解锁成就。

# 🥢 中国式饭局 · 点菜模拟器

[在线开单](https://shaoxiangm.github.io/diancai-simulator/)

先看人数、预算和客人忌口，再在复写纸联单上勾菜。交给后厨前，按住菜名右侧的 `≡`，在触屏或鼠标上拖动调整上菜顺序。出菜后翻到联单背面，看经理的红笔批注和职级印章。

- **一店一单**。12 家餐馆从 80 道菜品库中开出各自的动态菜单，每桌可选 32～36 道。
- **八大菜系严格区分**。闽东、闽南、广府、川渝、湖湘、鲁豫、沪上、东北各有招牌。点了别家菜系的招牌，经理会在联单上点名。
- **10 大奇葩成就**。四人一桌只叫一份白米饭，会收到「包厢要饭人」章。点封面上的黄色便签可翻看已得的章和其他线索。
- **纯前端单文件**。游戏的 HTML、CSS 和 JavaScript 都在 [index.html](./index.html) 中。下载后用浏览器打开即可游玩，关卡与成就保存在当前浏览器。
